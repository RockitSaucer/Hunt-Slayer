REG SLAYER — Changes 4.6 → 5.0 Beta
====================================
Date: 2026-08-03
Label: V5.0 Beta (production Hunt Slayer)

SUMMARY
-------
Promote the Test Offline (Hunt App 4.6) feature set to production Hunt Slayer
as a clean V5.0 Beta. Production (regslayer.com) now matches the test-offline
site for login, personal/shared maps, parties, and related map tools.

WHAT'S NEW vs production 4.5
----------------------------
1. Auth (Supabase HuntSlayer)
   - Sign-in / create account (username + password; email optional)
   - Session persists on device
   - Recovery codes + recover-password edge function

2. Personal + shared maps
   - Personal map cloud sync (local-first)
   - Create/join shared maps via 6-digit codes
   - Settings → Maps switcher; last-viewed map restored
   - Banner map name left of logo

3. Multi private maps + party location
   - Named private maps; rename; View/Rename in Settings → Maps
   - Party members under current shared map (nicknames + arrow colors)
   - Layers → Party overlay for members' pins/areas
   - Share location toolbar (red when sharing; auto-off after 1 hour)
   - Share location / pins across maps; copy to clipboard
   - Create pin: optional "also save to" other maps

4. Sync fixes (from 4.6 hotfixes)
   - Delete sync / dirty-flag correct; last-write-wins push
   - Immediate force-push after area delete
   - Create map invite auto-copies join message + deep link

5. Map chrome polish carried from 4.5→4.6 path
   - Slim bottom bar tools; weather dashboard; peak rut; compass/wind
   - Layers: Winter/Summer/Default satellite, roads, topo, parcels, etc.

CLEAN V5.0 BETA PUSH
--------------------
- This deploy ships **application code only**.
- Custom drawn shapes, tracking lines, pins, and tracks are **not** baked into
  the HTML. They live in each user's browser localStorage and Supabase map
  payloads.
- First-time accounts therefore start with a **clean empty map**.
- Future updates will keep using the same cloud/local keys so user drawings
  and tracks are preserved across app version bumps (do not change storage
  keys without a migration).
