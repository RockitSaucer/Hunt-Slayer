## Local full backup (pre-6.3)

```
Desktop/HuntApp/_push_hunt_slayer/index.html.bak-6.2-before-6.3
```

Restore just the HTML:

```powershell
cd Desktop\HuntApp\_push_hunt_slayer
Copy-Item index.html.bak-6.2-before-6.3 index.html -Force
# also set sw.js SHELL_CACHE back to reg-slayer-shell-v26 if needed
```

## Git undo

```powershell
cd Desktop\HuntApp\_push_hunt_slayer
git log -5 --oneline
# full roll back to 6.2:
git checkout v6.2-beta -- .
# or revert the 6.3 commit:
git revert HEAD
git push origin main
```
